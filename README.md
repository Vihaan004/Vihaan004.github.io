# Vihaan Patel's Personal Website

Source code for my personal website — portfolio, blog posts, and professional journey — highlighting my work in hardware engineering, software development, and AI.

Live at [vihaanpatel.tech](https://vihaanpatel.tech).

## Stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · Vercel Analytics. Blog posts are Markdown, rendered with `react-markdown` + `remark-gfm`, with front matter parsed by `gray-matter` and diagrams via `mermaid`.

## Development

```bash
npm install
npm run dev
```
